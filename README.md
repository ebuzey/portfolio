## 🚀 Local Development

Since the site relies on native Web APIs and Tailwind via CDN, no package manager (`npm`/`yarn`) or compilation step is required.

1. **Clone the repository:**
   ```bash
   git clone https://github.com/ebuzey/ebuzey.github.io.git
   cd ebuzey.github.io
   ```

2. **Serve locally:**
   You can open `index.html` directly in your browser or run any simple HTTP server:
   ```bash
   # Using Python
   python3 -m http.server 8000
   ```
   Then visit `http://localhost:8000`.
